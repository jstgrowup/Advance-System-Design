## Which database to choose?

- No one database will be able to solve the problem. There is a good variety of databases to solve problems

### Criteria

- Based on the team's knowledge, we can also prioritize a particular DB
- There is good knowledge of **RDBMS**, so you can prefer that
- If we need a graph-like structure, like social media applications, here you go for some graph-like databases. Databases like **Neo4j**, **InfiniteGraph**, etc. can be opted
- If you have unstructured data, this is probably schemaless, and you can store it in the form of documents. Then **document-based databases** are very useful
- If you want to store **key-value pairs**, let's say user ID <-> connection data, e.g. **Redis**, **DynamoDB** are a good choice
- Sometimes geolocation data is the use case. Then **geospatial** DBs like **Redis** geospatial, **Firebase** geospatial, etc. are useful
